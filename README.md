# TernaryLab — Beyond Binary

> A website exploring ternary computing, balanced ternary, and why three-state logic could change everything.

This is an informational website about ternary computing — the computing paradigm that uses three states instead of two.

## What's Inside

- Static HTML/CSS/JS website
- Covers ternary logic, balanced ternary, history (Setun), and the future of computing
- Interactive "Try It" section

## Run

Open `index.html` directly in a browser, or serve locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`

## Tech Stack

- HTML5 + CSS3 + vanilla JavaScript
- No build step, no dependencies
